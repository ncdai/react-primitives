---
title: Unstyled React primitives
description: Behaviour, accessibility and gestures, with no styles attached.
---

Each primitive ships as its own package, so you install only what you use. They
carry no CSS and no runtime dependencies, and expose their state as data
attributes for you to style against.

Styled versions built on top of them live in the
[chanhdai.com registry](https://chanhdai.com/components).
